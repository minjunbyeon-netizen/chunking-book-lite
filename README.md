# Chunking English — 청킹 영어 학습 교재

영어 청킹 학습 교재. Day 1~250.

## 구성
- `book-lite.html` — 본문 (영문/한글 청킹 + 일러스트). 브라우저로 열면 전체 교재가 표시됩니다.
- `img-lite/` — 일러스트 이미지 (약 6,000장)
- `pdf-output/by-day/` — Day별 PDF (250개)
- `tools/` — PDF 생성·검수 스크립트 (Python)

## 보기
`book-lite.html` 을 브라우저에서 엽니다. 이미지가 표시되려면 같은 폴더에 `img-lite/` 가 함께 있어야 합니다.

## PDF 저장
우측 상단 **PDF 저장하기** 버튼 → 전체 또는 특정 Day 선택 → 브라우저 인쇄 화면에서 "PDF로 저장".
연속 범위는 주소 끝에 `?range=10-50` 형식으로 지정할 수 있습니다.

## 개발자 참고 (직접 수정 시)
- **단일 파일 구조**: `book-lite.html` 한 파일에 Day 1~250 전체가 인라인으로 들어 있습니다(약 6.4MB). 빌드 단계·프레임워크 없이 HTML을 직접 편집합니다. 챙크 카드 구조가 6,000개 반복되므로, 같은 패턴을 그대로 복제해 추가합니다.
- **외부 글꼴·아이콘 CDN**: 상단 `<link>` 3개(Google Fonts, Pretendard, Font Awesome)는 인터넷에서 불러옵니다. 오프라인·폐쇄망에서 열면 글꼴과 아이콘이 기본체로 표시됩니다(본문 내용·이미지는 정상). 완전 오프라인이 필요하면 이 3개를 로컬 파일로 내려받아 경로를 바꾸십시오.
- **이미지 경로**: 모든 이미지가 `./img-lite/...` 상대경로입니다. `book-lite.html` 과 `img-lite/` 폴더는 항상 같은 위치에 함께 두어야 합니다.
- **PDF 페이지 구조 의존**: PDF 저장 기능이 "Day 1개 = 4페이지" 계산에 의존합니다(`startIndex=(day-1)*4`). 한 Day의 페이지 수를 늘리거나 줄이면 Day 선택·범위 출력이 어긋나므로, 페이지 단위 구조를 바꿀 때는 PDF 관련 스크립트도 함께 확인하십시오.
