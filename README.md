# Chunking English — 청킹 영어 학습 교재

영어 청킹 학습 교재. Day 1~250.

## 구성
- `book-lite.html` — 본문 (영문/한글 청킹 + 일러스트). 브라우저로 열면 전체 교재가 표시됩니다.
- `img-lite/` — 일러스트 이미지 (약 6,000장)
- `pdf-output/by-day/` — Day별 PDF (250개)
- `tools/` — PDF 생성·검수 스크립트 (Python)

## 보기
`book-lite.html` 을 브라우저에서 엽니다. 이미지가 표시되려면 같은 폴더에 `img-lite/` 가 함께 있어야 합니다.

## PDF 저장
우측 상단 **PDF 저장하기** 버튼 → 전체 또는 특정 Day 선택 → 브라우저 인쇄 화면에서 "PDF로 저장".
연속 범위는 주소 끝에 `?range=10-50` 형식으로 지정할 수 있습니다.
